# 02. Процесс расширения пара в h–s диаграмме

Процесс расширения — фундамент теплового расчёта. Он определяет располагаемый
теплоперепад, параметры в отборах и конечную точку (влажность пара).

## 2.1. Точка начала расширения

Заданы давление `p0` и температура `t0` свежего пара. По ним находятся энтальпия
и энтропия:

```
h0 = f(p0, T0)
s0 = f(p0, T0)
```

Через IF97:

```java
IF97 if97 = new IF97(IF97.UnitSystem.DEFAULT);
double h0 = if97.specificEnthalpyPT(p0, T0); // p0 [МПа], T0 [K] -> h [кДж/кг]
double s0 = if97.specificEntropyPT(p0, T0);  // s [кДж/(кг·К)]
```

Если задана температура в °C: `T0 [K] = t0 [°C] + 273.15`.

## 2.2. Дросселирование в клапанах

Пар дросселируется в стопорном и регулирующем клапанах. Дросселирование —
процесс при постоянной энтальпии:

```
h0' = h0 ;  p0' < p0
```

Потери от дросселирования включают в КПД (`η_oi`), либо явно смещают точку
начала процесса влево-вниз по изоэнтальпе. Для оценочного расчёта часто
принимают `p0' = (0.95…0.97)·p0`.

## 2.3. Изоэнтропный (располагаемый) теплоперепад

Идеальное расширение — при постоянной энтропии до давления `p_к`:

```
h_ks = f(p_к, s = s0)      энтальпия конца изоэнтропного расширения
H0   = h0 − h_ks           располагаемый теплоперепад, кДж/кг
```

Через IF97 (расширение до конденсатора `p_к`):

```java
double hks = if97.specificEnthalpyPS(pk, s0);
double H0 = h0 - hks;   // кДж/кг
```

Точке `ks` соответствует теоретическая скорость истечения (если бы всё
расширение шло в одном сопле):

```
c_max = sqrt(2 · H0 [кДж/кг] · 1000)   м/с
```

## 2.4. Действительный процесс

Реальное расширение идёт с ростом энтропии. Внутренний относительный КПД `η_oi`
показывает, какая доля располагаемого теплоперепада превращается в полезную работу:

```
H_i = H0 · η_oi             действительный теплоперепад
h_к = h0 − H_i              энтальпия в конце действительного расширения
```

Линия действительного процесса `0 → к` строится как политропа, отстоящая от
изоэнтропы `0 → ks` на накопленные потери. Для упрощённых расчётов достаточно
знать конечную точку `к`.

Степень сухости в конце расширения (важно для влажного пара, файл 06):

```java
double xk = if97.vapourFractionPH(pk, hk); // 0 <= xk <= 1
```

## 2.5. Промежуточный перегрев и отсеки

При промежуточном перегреве процесс разбивается на **отсеки** (например, ЦВД и
ЦСД/ЦНД):

1. Расширение в первом отсеке от `(p0, t0)` до давления `p_пп` перед промперегревом.
2. Вторичный перегрев пара до температуры `t_пп` в котле (при `p_пп`).
3. Расширение во втором отсеке от `(p_пп, t_пп)` до `p_к`.

Каждому отсеку соответствует свой располагаемый теплоперепад `H0_отсека`, а
промежуточный перегрев повышает КПД цикла и снижает влажность в конце расширения.

## 2.6. Параметры в отборах

Давления отборов задаются (регулятором или тепловой схемой). Для каждого отбора:
давление `p_отб` известно, энтальпию берут на линии действительного процесса
(или через КПД отсека), температуру — по (p, h) или (p, s) в однофазной зоне.

```java
double T_otb = if97.temperaturePH(p_otb, h_otb); // K
```

Если отвод происходит во влажном паре — используют `vapourFractionPH`.

## 2.7. Порядок построения (сводка)

1. Точка `0`: `(p0, t0)` → `h0, s0`.
2. Учёт дросселирования в клапанах.
3. Изоэнтропа до `p_к` → `h_ks`; `H0 = h0 − h_ks`.
4. Действительная точка `к` по `η_oi`.
5. Точки отборов и (при наличии) точки промежуточного перегрева.
6. Проверка конечной влажности `x_к ≥ 0.86…0.88` (ограничение по эрозии).
