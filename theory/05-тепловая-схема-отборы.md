# 05. Тепловая схема, регенерация и отборы

## 5.1. Назначение тепловой схемы

Тепловая схема турбоустановки определяет, куда и в каком количестве отводится
пар из турбины и как рекуперируется его теплота. Регенеративный подогрев
питательной воды повышает термодинамический КПД цикла: часть теплоты отборов
возвращается в цикл, снижая потери в конденсаторе.

## 5.2. Схема подогрева питательной воды

Питательная вода нагревается последовательно:

```
Конденсатор → ПНД (подогреватели низкого давления) → Деаэратор → ПВД (подогреватели высокого давления) → Котёл
```

- **ПНД** — греются паром низконапорных отборов.
- **Деаэратор** — удаление газов + подогрев, питается паром отбора.
- **ПВД** — греются паром высоконапорных отборов (например, перед котлом).

Целевая температура питательной воды `t_пв` задаётся (часто
`t_пв ≈ 0.65…0.75 · t_нас(p0)` для сверхкритических — вплоть до 270…300 °C).

## 5.3. Баланс поверхностного подогревателя

Для подогревателя с отбором пара и отводом дренажа:

```
α_отб · (h_отб − h_др) = α_пит · (h_вых − h_вх)
```

Отсюда доля расхода отбора:

```
α_отб = α_пит · (h_вых − h_вх) / (h_отб − h_др)
```

где:
- `α_отб = G_отб / G_0` — доля отбора (от расхода свежего пара `G_0`);
- `α_пит = G_пит / G_0` — доля питательной воды (≈ 1 при отсутствии утечек);
- `h_отб` — энтальпия греющего пара (с линии процесса);
- `h_др` — энтальпия дренажа (конденсата греющего пара);
- `h_вх, h_вых` — энтальпии воды до/после подогревателя.

Для деаэратора (смесительный подогреватель) баланс учитывает также подвод
основного конденсата и дренажей ПВД.

## 5.4. Параметры отборов

- **Давление отбора** определяется местом отбора вдоль процесса расширения.
- **Температура насыщения** в подогревателе: `T_нас = saturationTemperatureP(p_отб)`.
- **Недогрев** до температуры насыщения `δt_н` (обычно 3…7 °C):
  `T_вых = T_нас − δt_н`.
- Энтальпия воды на выходе: `h_вых = f(p, T_вых)`.

Через IF97:

```java
double Tnas = if97.saturationTemperatureP(p_otb);          // K
double h_out = if97.specificEnthalpyPT(p_otb, Tnas - dt);  // кДж/кг
double h_dr  = if97.specificEnthalpySaturatedLiquidP(p_otb); // энтальпия дренажа ~ h'
```

## 5.5. Материальный баланс по отсекам турбины

Расход через отсек определяется из баланса: весь пар, кроме отобранного выше по
потоку, проходит через данный отсек.

```
G_отсека = G_0 − Σ G_отборов(выше отсека)
```

или снизу вверх:

```
G_отсека = G_к + Σ G_отборов(ниже отсека, включая текущий)
```

Это объясняет «охлаждение» низконапорных ступеней: их расход меньше расхода
свежего пара, что учитывается при расчёте высот лопаток (файл 03).

## 5.6. Уравнение мощности с отборами

Внутренняя мощность — сумма по отсекам:

```
N_i = Σ G_отсека(j) · H_i_отсека(j)
```

Электрическая мощность:

```
N_э = N_i · η_м · η_г
```

## 5.7. Показатели экономичности ПТУ

- **Удельный расход пара:** `d_э = 3600 / (H_i · η_м · η_г)` [кг/(кВт·ч)] — на 1 кВт·ч.
- **Удельный расход теплоты:** `q_э = 3600 / η_э` [кДж/(кВт·ч)] (без учёта КПД котла).
- **КПД ПТУ:** `η_ПТУ = η_э` (относительно теплоты, подведённой к рабочему телу).

Регенерация увеличивает `η_ПТУ` за счёт уменьшения потери теплоты в конденсаторе.

## 5.8. Теплофикационные отборы

Для теплофикационных турбин добавляются регулируемые отборы пара на отопление и
горячее водоснабжение. Их влияние:
- уменьшение расхода через ЦНД (и его размеров);
- возможность работы в теплофикационном режиме с высоким суммарным КПД
  использования теплоты.

В Т-турбинах и ПТ-турбинах отборы регулируются мембранами/поворотными диафрагмами
в зависимости от тепловой нагрузки.

## 5.9. Порядок расчёта тепловой схемы

1. Задать давления отборов и целевую `t_пв`.
2. Для каждого подогревателя вычислить `h_отб`, `h_др`, `h_вх`, `h_вых`.
3. Из баланса подогревателя найти `α_отб`.
4. Проверить сходимость по расходам отсеков и мощности.
5. Итерационно увязать с расчётом процесса расширения (файл 04, этап 8).
