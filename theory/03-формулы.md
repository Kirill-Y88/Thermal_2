# 03. Основные формулы теплового расчёта

## 3.1. Располагаемый и действительный теплоперепад

```
H0 = h0 − h_ks            располагаемый (изоэнтропный), кДж/кг
H_i = H0 · η_oi           действительный (внутренний), кДж/кг
```

## 3.2. Мощность и расход пара

```
N_i = G · H_i                          внутренняя мощность, кВт (G кг/с, H_i кДж/кг)
N_э = N_i · η_м · η_г                  электрическая мощность
G   = N_э / (H0 · η_oi · η_м · η_г)    расход пара через турбину
```

где `η_м` — механический КПД, `η_г` — КПД генератора.

## 3.3. Истечение из сопла

```
c_1t = sqrt(2 · H_0c · 1000)   теоретическая скорость истечения, м/с  (H_0c в кДж/кг)
c1   = φ · c_1t                действительная скорость
Δh_c = (1 − φ²) · H_0c         потери в сопле, кДж/кг
```

`φ` — коэффициент скорости сопла: 0.93…0.98 (обычно ~0.97 для сопловых решёток).
Располагаемый теплоперепад сопла `H_0c` — часть `H0` ступени.

## 3.4. Окружная скорость

```
u = π · D · n / 60 = ω · D / 2
```

`D` — средний (расчётный) диаметр ступени, м; `n` — частота вращения, об/мин;
`ω = 2πn/60` — угловая скорость, рад/с.

## 3.5. Треугольники скоростей (активная ступень)

Вход в рабочую решётку (из сопла):

```
w1 = sqrt(c1² + u² − 2·c1·u·cos α1)      относительная скорость на входе
sin β1 = (c1 / w1) · sin α1              угол относительной скорости на входе
```

Выход из рабочей решётки:

```
w2 = ψ · w1                              ψ — коэффициент скорости лопатки: 0.85…0.95
c2 = sqrt(w2² + u² − 2·w2·u·cos β2)      абсолютная скорость на выходе
Δh_вс = c2² / 2000                       потери с выходной скоростью, кДж/кг
```

Проектный угол выхода `α2` и `β2` подбираются из условия минимальной выходной
потери; часто принимают `α2 ≈ 90°`.

## 3.6. КПД ступени

Относительный лопаточный КПД (работа на лопатках / располагаемый теплоперепад):

```
η_ол = 2 · φ² · (u/c1) · (cos α1 − u/c1) · (1 + ψ·cos β2 / cos β1)
```

Условие максимума `η_ол` для активной ступени:

```
(u / c1)_opt ≈ 0.5 · cos α1        (обычно u/c1 = 0.45…0.50)
```

Внутренний КПД ступени — с учётом дополнительных потерь:

```
η_oi(ст) = η_ол − (Δh_тр + Δh_вент + Δh_утечек) / H0
```

где `Δh_тр` — потери на трение диска, `Δh_вент` — вентиляционные,
`Δh_утечек` — протечки через зазоры.

## 3.7. Интегральные КПД

```
η_oi  = Σ(N_i ступеней) / (G · H0 турбины)   относительный внутренний турбины
η_oe  = η_oi · η_м                            относительный эффективный
η_э   = η_oi · η_м · η_г                      электрический КПД турбоагрегата
```

## 3.8. Геометрия решёток (уравнение неразрывности)

Из баланса расхода через решётку:

```
G · v = μ · π · D · l · c · sin α
```

Откуда высота лопатки:

```
l = G · v / (μ · π · D · c · sin α)
```

`v` — удельный объём пара за решёткой (м³/кг, из IF97 по `(p, T)` или `(p, h)`),
`μ` — коэффициент расхода решётки (0.95…0.98), `l` — высота лопатки (м).

Удельный объём через IF97:

```java
double v = if97.specificVolumePT(p, T);   // м³/кг
```

При расширении в ступени `v` растёт, поэтому высота лопатки от ступени к ступени
увеличивается (`D` также увеличивают). Отношение `l/D` (`d/l`) должно быть
достаточным, чтобы ограничить концевые потери.

## 3.9. Выбор числа ступеней

Суммарный теплоперепад разбивается на ступени с учётом допустимого теплоперепада
на ступень (ограничения по `u`, `c1`, углам, высоте лопатки):

```
H0 = Σ H0_i
```

Число ступеней `z` определяется так, чтобы теплоперепад каждой ступени лежал в
рекомендуемом диапазоне (для активных ступеней порядка 40…100 кДж/кг в зависимости
от диаметра и окружной скорости).

## 3.10. Типичные значения коэффициентов

| Коэффициент | Смысл | Диапазон |
|-------------|-------|----------|
| `φ` | скорость сопла | 0.93…0.98 |
| `ψ` | скорость рабочей лопатки | 0.85…0.95 |
| `μ` | коэффициент расхода | 0.95…0.98 |
| `α1` | угол выхода сопла | 12…20° |
| `β2` | угол выхода лопатки | 15…30° |
| `u/c1` | отношение скоростей | 0.45…0.50 |
| `η_oi` | внутренний КПД | 0.80…0.92 |
