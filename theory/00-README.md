## Источник свойств рабочего тела

В проекте подключена библиотека
`com.hummeling:if97:2.0.0` — реализация IAPWS-IF97 (свойства воды и водяного пара).
Она заменяет ручную работу с таблицами и диаграммой `h–s`.

Подробный справочник соответствия «формула → метод IF97» — в файле
[06-спецвопросы-и-if97.md](06-спецвопросы-и-if97.md).

## Системы единиц

Библиотека `if97` поддерживает несколько систем единиц (см. `IF97.UnitSystem`):

| UnitSystem | Давление p | Температура T | Энтальпия h | Энтропия s |
|------------|-----------|---------------|-------------|------------|
| `DEFAULT` | МПа | K | кДж/кг | кДж/(кг·К) |
| `ENGINEERING` | бар | °C | кДж/кг | кДж/(кг·К) |
| `SI` | Па | K | Дж/кг | Дж/(кг·К) |
| `IMPERIAL` | psi | °F | BTU/lb | BTU/(lb·R) |

> По умолчанию используется `DEFAULT`. В формулах ниже энергия берётся
> в кДж/кг, если не указано иное, а скорости — в м/с (1 кДж/кг = 1000 м²/с²).

## Обозначения величин

| Обозначение | Величина | Размерность |
|-------------|----------|-------------|
| `p` | давление | МПа (бар) |
| `t`, `T` | температура | °C, K |
| `h` | удельная энтальпия | кДж/кг |
| `s` | удельная энтропия | кДж/(кг·К) |
| `v` | удельный объём | м³/кг |
| `x` | степень сухости пара | – |
| `G` | массовый расход пара | кг/с |
| `N` | мощность | кВт (МВт) |
| `H0` | располагаемый теплоперепад | кДж/кг |
| `H_i` | действительный теплоперепад | кДж/кг |
| `c` | абсолютная скорость | м/с |
| `w` | относительная скорость | м/с |
| `u` | окружная скорость | м/с |
| `α`, `β` | углы потока (абс., отн.) | град. |
| `D` | средний диаметр ступени | м |
| `n` | частота вращения | об/мин |
| `η` | КПД | – |

Индексы: `0` — начальные параметры, `к` — конденсатор/конечная точка,
`s` — изоэнтропный (адиабатный) процесс, `i` — внутренний, `oi` — относительный
внутренний, `ол` — относительный лопаточный, `м` — механический, `г` — генератор,
`э` — электрический, `с` — сопло, `л` — рабочая лопатка, `вс` — выходная скорость.
