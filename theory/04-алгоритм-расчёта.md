# 04. Пошаговый алгоритм теплового расчёта

Ниже — порядок расчёта с указанием входов и выходов каждого этапа.

## Этап 1. Исходные данные

**Вход:** тип турбины, `N_э`, `p0`, `t0`, `p_к`, `n`, отборы, `t_пв`, `η_м`, `η_г`,
ограничения.
**Выход:** заполненный набор исходных параметров.

## Этап 2. Построение процесса расширения (h–s)

**Вход:** `p0, t0, p_к` (+ параметры промперегрева/отборов).
**Выход:** `h0, s0, h_ks, H0, h_к`, точки отборов.

Порядок:
1. `h0, s0` по `(p0, T0)`.
2. Учёт дросселирования в клапанах.
3. Изоэнтропа до `p_к` → `h_ks`; `H0 = h0 − h_ks`.
4. Задание `η_oi` (оценка), расчёт `H_i`, `h_к`, проверка `x_к`.

Детали — в [02-процесс-расширения-hs.md](02-процесс-расширения-hs.md).

## Этап 3. Определение расхода пара

**Вход:** `N_э, H0, η_oi, η_м, η_г`.
**Выход:** `G` через турбину.

```
G = N_э / (H0 · η_oi · η_м · η_г)
```

Для турбин с отборами расход уточняется по отсекам (этап 6).

## Этап 4. Разбиение теплоперепада по цилиндрам/отсекам

**Вход:** `H0`, структура турбины (число цилиндров/отсеков), давления разбивки.
**Выход:** `H0_отсека` для каждого отсека.

Для турбины с промперегревом `H0` разделяется на отсеки в точках перегрева и
отборов.

## Этап 5. Предварительное разбиение по ступеням и выбор числа ступеней

**Вход:** `H0_отсека`, ограничения по диаметрам и окружным скоростям.
**Выход:** число ступеней `z`, `H0_i` каждой ступени, средние диаметры `D_i`.

Проверки: `u = π·D·n/60` не превышает допустимую; `l/D` (высота к диаметру) в
норме; теплоперепад на ступень в рекомендуемом диапазоне.

## Этап 6. Детальный расчёт ступеней

Для каждой ступени `i` по [03-формулы.md](03-формулы.md):

1. `u = π·D·n/60`.
2. Задать `α1`, `β2`, `φ`, `ψ`.
3. `c_1t = sqrt(2·H_0c·1000)`, `c1 = φ·c_1t`.
4. `w1`, `β1`; `w2 = ψ·w1`; `c2`, `Δh_вс`.
5. Потери `Δh_c, Δh_л, Δh_вс, Δh_тр, Δh_вент, Δh_утечек`.
6. `η_ол`, `η_oi(ст)`.
7. Высоты решёток `l_c, l_л` по уравнению неразрывности (нужен `v` из IF97).
8. `H_i(ст) = H0_i · η_oi(ст)`.

**Выход по ступени:** треугольники, потери, КПД, геометрия.

## Этап 7. Учёт отборов (тепловая схема)

**Вход:** параметры и давления отборов, `t_пв`, схема подогревателей.
**Выход:** доли расходов отборов `α_отб`.

Материальный баланс по отсекам: расход через отсек равен расходу на конденсатор
плюс все отборы, отведённые за этим отсеком (ниже по потоку):

```
G_отсека = G_к + Σ G_отборов(за отсеком)
```

Методика балансов подогревателей — в [05-тепловая-схема-отборы.md](05-тепловая-схема-отборы.md).

## Этап 8. Итерационное уточнение

Причины итераций: `η_oi` зависит от геометрии, геометрия — от `v`, который зависит
от процесса; доли отборов — от процесса, а расход по отсекам — от отборов.

Схема:
1. Задать начальные оценки (`η_oi`, диаметры, доли отборов).
2. Выполнить этапы 2–7.
3. Пересчитать расходы по отсекам с учётом отборов.
4. Повторить до сходимости.

Критерии останова:
- изменение суммарной мощности `|ΔN| / N < ε_N` (например, 0.1 %);
- изменение КПД `|Δη_oi| < ε_η`;
- изменение расходов отборов.

## Этап 9. Суммирование результатов и проверка

**Выход:**
- внутренняя `N_i = Σ G_отсека · H_i_отсека`;
- электрическая `N_э = N_i · η_м · η_г`;
- интегральные КПД `η_oi, η_oe, η_э`;
- конечная влажность `x_к` в норме.

**Проверка баланса:** рассчитанная `N_э` совпадает с заданной; параметры всех
точек физически корректны; ограничения соблюдены.
