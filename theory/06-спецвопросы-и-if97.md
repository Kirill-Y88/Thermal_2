# 06. Специальные вопросы и справочник IF97

## 6.1. Влажный пар в последних ступенях

В конденсационных турбинах последние ступени работают во влажном паре (`x < 1`).
Особенности:
- рост потерь от влажности (капли не разгоняются потоком);
- ориентировочно +1 % потерь КПД на каждый 1 % влажности (в рабочем диапазоне);
- **эрозия** входных кромок рабочих лопаток каплями → ограничение конечной
  влажности `x_к ≥ 0.86…0.88`.

Учёт: термодинамические свойства влажного пара по IF97 через
`vapourFractionPH/PS` и параметры насыщения.

```java
double x = if97.vapourFractionPH(p, h);   // степень сухости
```

## 6.2. Промежуточный перегрев

Вторичный перегрев пара (в котле) между отсеками:
- повышает КПД цикла;
- снижает конечную влажность (`x_к` растёт);
- требует разделения процесса на отсеки (файл 02).

Расчёт: после первого отсека пар возвращается в котёл, где перегревается при
давлении `p_пп` до `t_пп`; далее расширяется во втором отсеке.

## 6.3. Осевая сила и разгрузка ротора

Перепад давлений на ступень создаёт осевое усилие на ротор. Для разгрузки:
- разгрузочный поршень (думмис);
- встречное направление потока в цилиндрах (например, ЦНД двухпоточный);
- осевой сдвиг проточной части.

Тепловой расчёт даёт распределение давлений по ступеням — исходные данные для
расчёта осевой силы.

## 6.4. Переменные режимы

При частичных нагрузках меняются расход, давления и КПД. Основные подходы:
- **метод Стодолы–Флюгеля** — связь расхода и давлений за ступенью/отсеком:

```
G / G_ном = sqrt( (p² − p_вых²) / (p_ном² − p_вых_ном²) ) · sqrt(T_ном / T)
```

- для конденсационных турбин при `p_вых ≈ 0`: `G / G_ном ≈ p / p_ном`;
- регулирующая ступень работает с переменной степенью парциальности;
- режимные характеристики строят по расходу/давлению/мощности.

## 6.5. Прочностные ограничения

- окружная скорость лопаток ограничена прочностью (обычно `u ≤ 200…250 м/с`,
  для титановых/специальных — выше);
- напряжения в корневом сечении лопатки;
- вибрационная надёжность (собственные частоты, резонансы).

Тепловой расчёт задаёт `u`, `D`, `l`, что служит входом прочностного расчёта.

## 6.6. Справочник соответствия «формула → метод IF97»

| Задача расчёта | Метод `com.hummeling.if97.IF97` |
|----------------|--------------------------------|
| Энтальпия по `(p, T)` | `specificEnthalpyPT(p, T)` |
| Энтропия по `(p, T)` | `specificEntropyPT(p, T)` |
| Энтальпия по `(p, s)` (изоэнтропа) | `specificEnthalpyPS(p, s)` |
| Энтропия по `(p, h)` | `specificEntropyPH(p, h)` |
| Температура по `(p, h)` | `temperaturePH(p, h)` |
| Температура по `(p, s)` | `temperaturePS(p, s)` |
| Удельный объём по `(p, T)` | `specificVolumePT(p, T)` |
| Удельный объём по `(p, s)` | `specificVolumePS(p, s)` |
| Степень сухости по `(p, h)` | `vapourFractionPH(p, h)` |
| Степень сухости по `(p, s)` | `vapourFractionPS(p, s)` |
| Температура насыщения по `p` | `saturationTemperatureP(p)` |
| Давление насыщения по `T` | `saturationPressureT(T)` |
| Энтальпия кипящей жидкости `h'` | `specificEnthalpySaturatedLiquidP(p)` |
| Энтальпия сухого пара `h''` | `specificEnthalpySaturatedVapourP(p)` |
| Удельный объём `v'` / `v''` | `specificVolumeSaturatedLiquidP/VapourP(p)` |
| Энтропия `s'` / `s''` | `specificEntropySaturatedLiquidP/VapourP(p)` |
| Скорость звука (критический расход) | `speedOfSoundPT(p, T)` |
| Изобарная теплоёмкость | `isobaricHeatCapacityPT(p, T)` |
| Показатель изоэнтропы | `isentropicExponentPT(p, T)` |
| Динамическая вязкость | `dynamicViscosityPT(p, T)` |
| Область (регион) по `(p, T)` | `getRegionPT(p, T)` |

Все методы бросают `OutOfRangeException` при выходе за область применимости
IF97 (см. 6.7).

## 6.7. Область применимости и единицы

- IF97 охватывает давление до **100 МПа** и температуру до **2273 K** (по регионам).
- При выходе за диапазон методы бросают `com.hummeling.if97.OutOfRangeException` —
  в расчётном коде это нужно обрабатывать (валидация исходных данных).
- Единицы задаются при создании объекта:

```java
IF97 if97 = new IF97(IF97.UnitSystem.DEFAULT);      // МПа, K, кДж/кг
IF97 eng  = new IF97(IF97.UnitSystem.ENGINEERING);  // бар, °C, кДж/кг
```

| UnitSystem | p | T | h | s |
|------------|---|----|----|----|
| `DEFAULT` | МПа | K | кДж/кг | кДж/(кг·К) |
| `ENGINEERING` | бар | °C | кДж/кг | кДж/(кг·К) |
| `SI` | Па | K | Дж/кг | Дж/(кг·К) |
| `IMPERIAL` | psi | °F | BTU/lb | BTU/(lb·R) |

## 6.8. Проверочный пример (эталон для тестов)

Исходные данные:
- свежий пар: `p0 = 24 МПа`, `t0 = 540 °C` → `T0 = 813.15 K`;
- конденсатор: `p_к = 0.004 МПа`;
- принятый `η_oi = 0.87`.

Результат (проверено запуском библиотеки `if97` 2.0.0, `UnitSystem.DEFAULT`):

```
Область точки (p0,T0) : Region 2
h0                    = 3318.78 кДж/кг
s0                    = 6.1723  кДж/(кг·К)
T_нас(p_к)            = 302.11 K
h_ks (изоэнтропа)     = 1858.51 кДж/кг
H0 = h0 − h_ks        = 1460.27 кДж/кг
H_i = H0 · 0.87       = 1270.43 кДж/кг
h_к = h0 − H_i        = 2048.34 кДж/кг
x_к                   = 0.792   (влажный пар, > 0.88 не выполнено —
                                 для сверхкритических параметров это типично,
                                 промперегрев повышает x_к)
```

Эти числа можно использовать как эталон при написании модульных тестов
расчётного ядра.
