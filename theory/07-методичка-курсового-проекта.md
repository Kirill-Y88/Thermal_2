# 07. Методичка курсового проекта — структура и порядок расчёта

Источник: файл `university/Методичка 2 по курс. проекту ... .doc`
(68 страниц в редакторе, 66 страниц PDF). Ниже — структура и порядок расчёта в
соответствии с методичкой.

Формулы в исходном `.doc` — **582 вставленных OLE-объекта Microsoft Equation 3.0**
(не растровые картинки), плюс 6 схем-объектов Microsoft Visio; при текстовом
извлечении формулы теряются, поэтому здесь по каждому пункту приведена его суть и
классическая формула. Справочные таблицы и графики методички оцифрованы отдельно в
[08-справочные-данные-методички.md](08-справочные-данные-методички.md).

## 7.1. Тема и объём проекта

Тема — **разработка проточной части одноцилиндровой турбины** (или отдельного
цилиндра высокого давления — ЦВД) турбины большой мощности.

Проект содержит:
- расчётную часть (тепловой и прочностной расчёт);
- графическую часть (2 листа А1);
- пояснительную записку.

Состав графической части:
- **Лист 1** — продольный разрез турбины (масштаб 1:5) + проточная часть одной
  рассчитанной ступени в масштабе 2:1.
- **Лист 2** — детали, рассчитанные на прочность (диафрагма первой ступени и
  рабочая лопатка последней ступени), в масштабе 1:2.

## 7.2. Исходные данные к расчёту

- **Номинальная электрическая мощность** `Nн`, МВт.
- **Параметры перед стопорным клапаном:** давление `P0`, бар; температура `t0`, °C.
- **Конечное давление пара** `Pк`, бар.
- **Частота вращения** `n = 3000 об/мин (50 1/с)` — для всех вариантов.
- Дополнительно: **прототип** турбины, **детали для прочностного расчёта**,
  **спецзадание**.

> Обратите внимание: в методичке давление задаётся в **бар**, температура в
> **°C**. Это соответствует `IF97.UnitSystem.ENGINEERING` (бар, °C, кДж/кг).

## 7.3. Раздел 1. Предварительные расчёты

### 1) Экономическая мощность и оценка расхода пара

Проточная часть проектируется на **экономическую мощность** `Nэк`:

```
Для турбин малой/средней мощности и турбин с противодавлением:
    Nэк = (0.7 – 0.8) · Nн
Для базовых турбин большой мощности и турбин АЭС:
    Nэк = (0.9 – 1.0) · Nн
```

Давление перед соплами первой ступени (с учётом потерь в стопорном и
регулирующих клапанах) меньше `P0`; давление за последней ступенью учитывает
потери в выхлопном патрубке:

```
Скорость в выхлопном патрубке:
    конденсационные турбины:         Cвп = 100…120 м/с
    турбины с противодавлением, ЦВД: Cвп = 50…80 м/с
коэффициент λ = 0.08…0.10
```

Расход пара на турбину (первое приближение):

```
G = Nэк / (H0 · ηоэ)      кг/с
```

где `ηоэ` — относительный электрический КПД (по табл. 1 методички, зависит от
мощности), `Nэк` в кВт.

### 2) Регулирующая ступень

Для регулирующей ступени выбирается тип (**одновенечная** или
**двухвенечная**). Двухвенечная (Curtis) применяется при большом теплоперепаде,
даёт больший теплоперепад на ступень и рост высоты лопаток в первых
нерегулируемых ступенях.

Оценка размеров регулирующей ступени:
- **фиктивная скорость** `Ca = sqrt(2·H0_рс·1000)`;
- **окружная скорость** `U = (U/Ca)·Ca`;
- **средний диаметр** `d = 60·U / (π·n)`;
- **теплоперепад сопловой решётки** `h0c = (1 − ρт)·H0_рс`, где `ρт` — суммарная
  степень реактивности (`0.03…0.07` для одновенечных, `0.06…0.12` для
  двухвенечных);
- **проходная площадь сопловой решётки** `f1 = G·v1t / (μ1·c1t)`, `μ1 ≈ 0.97`;
- **произведение степени парциальности и высоты сопловых лопаток**;
- **степень парциальности** `e` (`a = 0.5` для одновенечной, `a = 0.33` для
  двухвенечной);
- **высота сопловых лопаток** `l1`.

Минимально допустимый теплоперепад регулирующей ступени — **70…75 кДж/кг**.
Если он меньше, снижают `U/Ca` относительно оптимального (КПД ступени падает).

### 3) Предельная мощность и число выхлопов

**Предельная мощность** однопоточной турбины ограничена размерами последней
ступени (прочность лопаток). Предельные размеры при `n = 3000 об/мин`:
- стальные лопатки: `l2 = 960…1050 мм`, `dср = 2480…2550 мм`;
- титановые сплавы: `l2 = 1200 мм`, `dср = 3000 мм`.

Параметры формулы предельной мощности:
- `m` — влияние отборов на регенерацию (`1.1…1.2` с регенерацией, иначе `1`);
- `kразгр = 2.0…2.4` — снижение напряжений растяжения по высоте лопатки;
- `[σ]` — допустимое напряжение, МПа (легированная сталь `380…450`, титан `800`);
- `ρ` — плотность (сталь `8000`, титан `4500` кг/м³);
- `С2z` — скорость выхода из последней ступени (малая/средняя мощность
  `16…20 кДж/кг`, большая — `25…45 кДж/кг`).

Если `Nпр > Nн` — турбина однопоточная (один выхлоп). Если `Nпр < Nн` —
несколько выхлопов (например, двухпоточный ЦНД).

### 4) Число нерегулируемых ступеней и законы изменения корневого диаметра

Три закона изменения корневого диаметра `dk`:
- `dk = const` по всем ступеням;
- понижение `dk` по потоку пара;
- повышение `dk`.

Одноцилиндровые конденсационные турбины малой мощности — `dk = const` в ЧВД и
ЧСД, `dk = varia` в ЧНД. Постоянство `dk` унифицирует хвостовое крепление лопаток
и профили. Обычно проектируют по закону изменения **корневых** диаметров (а не
средних). Число ступеней отсека определяется по диаграмме (рис. 6 методички) с
учётом **коэффициента возврата тепла** `q = 0.02…0.03`.

### 5) Предварительный расчёт ЧВД / ЧСД / ЧНД

- Первые ступени: обеспечить `l1, l2 ≥ 12 мм` и по возможности полный подвод
  (`e = 1`); при необходимости — парциальный подвод (`e < 1`).
- Степень реактивности первой ступени `ρт = 0.05…0.10`, `α1эф = 11…12°`,
  `φ = 0.93…0.96`, `μ = 0.96…0.98`.
- Средний диаметр последней ступени отсека — по упрощённому уравнению
  неразрывности через удельные объёмы за первой и последней ступенями.
- Проверка ожидаемых углов: в ЧВД `α1эф ≥ 8°`, `β2эф ≥ 12°` (для подбора профилей
  из атласа МЭИ).
- Средний диаметр последней ступени ЧНД — из условия `α2 ≈ 90°` и допустимой
  выходной скорости. Также можно выбирать из ряда типовых ступеней ЧНД ЛМЗ по
  величине объёмного расхода `G·V2`.

## 7.4. Раздел 2. Построение процесса расширения и уточнение расхода

- Уточняется относительный внутренний КПД **отдельно для регулирующей ступени и
  для отсеков** ЧВД, ЧСД, ЧНД.
- КПД ЧСД и ЧНД учитывают **коэффициент влажности** (для части теплоперепада,
  лежащей в области влажного пара).
- Определяются полезно использованные теплоперепады отсеков и суммарный:
  `Hi = Σ Hi_отсека`.
- Строится **реальный процесс расширения** в h–s с учётом найденных КПД отсеков.
- Уточняется расход пара:

```
G = Nэк / (Hi · ηм · ηг)      кг/с
```

При проектировании турбины с противодавлением или отдельного ЦВД вся проточная
часть принимается за **один отсек (ЧВД)**.

## 7.5. Раздел 3. Детальный расчёт проточной части

- Детально рассчитываются **пять ступеней**: первые две (включая регулирующую)
  и последние три.
- Проходная площадь сопловой решётки — по-разному при `M1t > 1` и `M1t < 1`.
- Коэффициенты скорости `φ, ψ` и расхода `μ1, μ2` — по графикам (рис. 7–9) или
  по эмпирическим формулам от `b1/l1`, `b2/l2`; для влажного пара — с поправкой
  на влажность (оцифрованные графики и формулы — в
  [08-справочные-данные-методички.md](08-справочные-данные-методички.md), п. 8.5).
- При сверхзвуке — отклонение потока в косом срезе по **формуле Бэра**.
- Промежуточные ступени считаются **от параметров торможения** (с учётом
  кинетической энергии потока из предыдущей ступени).
- Высоты лопаток промежуточных ступеней берутся из предварительного расчёта (по
  `d` и `dk`), а не из уравнения неразрывности.
- Лопаточный КПД `ηол` определяется **двумя способами** (через потери энергии и
  по треугольникам скоростей); расхождение — не более **1.5 %**.
- Затем учитываются дополнительные потери (трение, парциальность, утечки,
  влажность) → `ηoi` ступени.

## 7.6. Раздел 4. Расчёт закрутки последней ступени

Для длинных лопаток ЧНД (большая веерность) поток по высоте меняется, поэтому
лопатки закручивают. Расчёт по кольцевым участкам одинаковой высоты `Δr`:
- разбиение по высоте на струйки;
- степень реактивности участка растёт от корня к периферии (`ρтк = 0.03…0.05` в
  корне);
- расходы по участкам `ΔGi`;
- далее каждый участок — по одномерной методике;
- КПД ступени — суммирование мощностей по участкам / располагаемая мощность.

## 7.7. Раздел 5. Расчёты на прочность

1. **Осевое усилие на ротор** — две составляющие: на венце рабочей решётки и на
   поверхности диска (с учётом разгрузочных отверстий и протечек через уплотнения).
   Считается для первой нерегулируемой ступени и умножается на число ступеней.
2. **Лопатка последней ступени** — напряжения растяжения (центробежная сила
   профиля и бандажа) и изгиба (окружное и осевое усилие от потока). Опасное
   сечение — корневое.
   - `σраст` от `Fц`; изгибное `σизг = M/Wmin`.
   - Допустимое `σизг`: `35…45 МПа` при полном подводе, `15…25 МПа` при
     парциальном.
   - Суммарное напряжение → выбор материала по коэффициенту запаса прочности.
3. **Диск** — метод «двух расчётов» (вращающийся и невращающийся) от внутреннего
   радиуса к внешнему; строится эпюра напряжений; выбор стали по максимальному
   тангенциальному напряжению.
4. **Диафрагма первой нерегулируемой ступени** — максимальное напряжение и
   прогиб; `p0, p1` берутся из расчёта ступени.

- **Приложение 1** — порядок расчёта **одновенечной ступени** (54 пункта).

- **Приложение 5** — расчёт **диска** произвольного профиля.
